VERIFY / 02

Don't trust — verify

Every airdrop, testnet and channel post gets the same three verdicts before anything else happens. Updates go out on Telegram @airdropfind — and even those get checked for fake sources first.

Verified

Independent coverage exists: a real team, public docs, and token / points / prize details published by the project itself. Still burner-only, still small first.

Not verified

The project itself can't be confirmed — zero independent coverage, no team, no docs, no token details. Watched, not joined. No wallet connects.

Speculation only

No prizes stated anywhere — no amount, no token, no points system, on the site or in any search result. If wing joins at all: register, do tasks, never connect a wallet holding anything.

  • ✓
    Source first. Is this the real site / channel, or a lookalike? Cross-check the handle and domain against a second independent source.
  • ✓
    Coverage check. Team, docs and token details findable outside the project's own posts? If not, it's “Not verified” by default.
  • ✓
    Prize check. Amount, token or points published? “None stated” is recorded as none stated — never rounded up into a promise.
  • ✓
    Chain check. Before adding any EVM network, verify chain ID, RPC, currency and explorer on chainlist.org against official docs. Chainlist never asks for a seed — any site that does is a scam.
  • ✓
    Wallet check. Burner only, testnet first, smallest amount first. A funded wallet never touches an unverified project.
